System identification

building-rom-automation

Automates reduced-order building envelope models with an RC structure, trained and tested on EnergyPlus simulation data. A config-driven pipeline edits IDFs, runs simulations, processes outputs and runs EKF-based 4R2C identification.

Drawing

Highlights

  • Full pipeline from raw ResStock IDFs to processed EKF training data, with config consistency checks.
  • Two-pass augmented-state EKF freezes parameters for held-out validation and test evaluation.
  • Candidates in the parameter grid are scored by RMSE on the validation segment.

Technologies

  • Python
  • EnergyPlus
  • Extended Kalman Filter
  • ResStock
  • RC modeling
  • YAML configs
